# CloudLab Development Instructions

## Steps

1. Clone the repository:
   git clone <github.com/jaaywill4/Course_Project>

2. Navigate into the project:
   cd Course_Project

3. Run the application:
   docker copose up --build

4. Access the application:
   https://localhost:3000

## Notes

- Docker must be installed on the CloudLab node
- Ports 3000 and 6379 must be open
